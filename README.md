# Cisco Packet Tracer Projects

This repository contains my Cisco Packet Tracer networking practice projects and configurations.

## 📌 About

I created these projects while learning and practicing computer networking using Cisco Packet Tracer.

The projects include basic network topologies, routers, switches, PCs, IP addressing, and device configuration.

## 🛠️ Software Used

- Cisco Packet Tracer 9.0.1
- Cisco IOS

## 📂 Projects

| File | Description |
|------|-------------|
| `2 r.pkt` | Router configuration practice |
| `2 switch.pkt` | Switch configuration practice |
| `4 pc.pkt` | Network with 4 PCs |
| `cisco topology.pkt` | Basic Cisco network topology |
| `one router.pkt` | Single router configuration |
| `pc4.pkt` | PC networking practice |
| `saves.pkt` | Packet Tracer practice configuration |

## 🌐 Networking Concepts Practiced

- Router Configuration
- Switch Configuration
- IP Addressing
- Subnet Mask
- GigabitEthernet Interface Configuration
- `no shutdown`
- Basic Cisco IOS Commands
- Network Topology
- PC-to-PC Communication
- Router-to-Network Communication

## 🚀 How to Use

1. Download or clone this repository.
2. Open Cisco Packet Tracer 9.0.1.
3. Open any `.pkt` file.
4. Check the topology and device configurations.
5. Practice the commands and network setup.
